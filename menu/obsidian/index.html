Obsidian: Private Multimodal AI That Sees, Reads, and Responds — On Your Hardware

Obsidian is a compact multimodal instruction model designed to handle image understanding, document analysis, and visual question answering without sending a single pixel to an external server. Built for on-premise deployment, Obsidian gives enterprises a self-hosted vision-language capability that fits on modest hardware and integrates cleanly into existing workflows.

If your team needs AI that can look at a chart, read a form, or describe a product image — and you cannot afford the data exposure of cloud vision APIs — Obsidian is worth a serious evaluation.

It runs via ollama run obsidian — no API key, no image logging, no per-query billing.

---

What Obsidian Actually Does

  • Visual question answering — ask natural language questions about any image and receive structured, contextual answers
  • Document and form understanding — extract key fields, summarize content, and interpret scanned materials including mixed-layout documents
  • Image captioning and description — generate accurate, detailed descriptions for product images, technical diagrams, and operational photography
  • Instruction-following on visual inputs — handle complex multi-step prompts that combine image context with text instructions
  • Lightweight deployment footprint — runs efficiently on CPU-only hardware, making it accessible without GPU investment for teams just getting started
---

Who Should Run Obsidian On-Premise

  • Manufacturing and quality control teams — inspect product images, flag defects, and generate structured inspection reports on local hardware near the production line
  • Healthcare and clinical operations — process medical images, intake forms, and scanned patient documents entirely on-premise, satisfying HIPAA requirements without cloud exposure
  • Legal and compliance departments — extract and summarize content from scanned contracts, redlined documents, and evidence exhibits without routing materials through third-party APIs
  • Retail and e-commerce operations — automate product image tagging, description generation, and catalog enrichment using local compute rather than paying per-image API fees
  • Government and defense contractors — deploy multimodal AI in classified or restricted environments where internet-connected vision tools are not permitted

Deployment Tiers and Compute Requirements

Tier 1 — CPU Deployment: Obsidian Q4

  • RAM required: 4–8GB
  • Hardware: Developer laptop, AWS Lightsail 4GB or 8GB instance
  • AWS cost: Lightsail 8GB ~$40/month
  • Speed: 3–8 tokens/sec on CPU
  • Best for: Batch document processing, internal tooling, pilot evaluation workloads

Run it: ollama run obsidian

Tier 2 — GPU Deployment: Obsidian Q4 on 8GB VRAM

  • VRAM required: 8GB
  • Hardware: AWS g4dn.xlarge (T4 16GB), RTX 3070, RTX 4060, or equivalent
  • AWS cost: ~$0.526/hour on-demand; ~$0.16/hour spot
  • Speed: 25–45 tokens/sec
  • Best for: Interactive internal tools, concurrent user workloads, moderate image processing volumes

Run it: ollama run obsidian

Tier 3 — High-Throughput GPU: Obsidian Q8 on 16GB+ VRAM

  • VRAM required: 16GB+
  • Hardware: AWS g4dn.2xlarge, RTX 4080, RTX 3090, or equivalent
  • AWS cost: ~$0.752/hour on-demand; ~$0.23/hour spot
  • Speed: 40–70 tokens/sec
  • Best for: Production-scale document pipelines, high-volume image analysis, real-time visual QA applications

Run it: ollama run obsidian:q8_0

The Real Cost of Cloud Vision APIs

  • Every image submitted to a cloud vision API is logged, potentially stored, and subject to that provider's terms of service — creating real liability for organizations handling proprietary or regulated imagery
  • Google Vision API charges per image at scale; for a team processing 50,000 images per month, costs compound into a substantial ongoing line item
  • GPT-4V and similar APIs transmit your documents, diagrams, and photographs to infrastructure you do not control — proprietary product designs, patient records, and legal exhibits included
  • Obsidian eliminates both risks: your images never leave your infrastructure, and your cost is fixed at the hardware level regardless of volume
