What Is Nous Hermes 2?

Nous Research is a small, community-oriented AI lab that built its reputation by asking a deceptively simple question: can we fine-tune open-weight base models better than the base model labs themselves? For the Hermes series, the answer has consistently been yes.

Nous Hermes 2 is a family of instruction-tuned models fine-tuned on a large, carefully curated dataset that Nous Research assembled from synthetic and human sources. The training data — often referred to informally as the "Nous dataset" — emphasizes reasoning depth, instruction diversity, and what the team calls "thoughtful alignment": safety behaviors that reflect actual harm potential rather than blanket topic refusals.

The practical result is a model that feels more like a knowledgeable colleague than a corporate chatbot. It will discuss topics that trigger ChatGPT's refusal filters, provided the context is reasonable. It also scores notably well on MT-Bench's multi-turn coherence tests, where maintaining conversational context across a long exchange matters more than raw knowledge recall.

🟣
Why the community converged on Nous Hermes

Between 2023 and 2024, several local AI leaderboards showed Nous Hermes 2 outperforming the official Llama 2 Chat and Mistral Instruct fine-tunes on MT-Bench — despite using the same base weights. The difference was entirely in the fine-tuning dataset and training approach. This made Nous Research the go-to source for "better than official" model variants and drove significant community adoption.

Model Variants: Which One to Use

Nous Hermes 2 is not a single model — it's a family of fine-tunes across different base models and sizes. Choose based on your available hardware and use case.

Most Popular

Nous Hermes 2 Mistral 7B DPO

Base: Mistral 7B v0.1  |  Context: 32K
RAM (INT4): ~5–6GB  |  Ollama tag: nous-hermes2

The default choice for most users. Mistral's strong base + Nous fine-tuning + DPO alignment. Best balance of quality, speed, and hardware requirements. Runs comfortably on 8GB RAM machines.

Step Up

Nous Hermes 2 Llama 2 13B

Base: Llama 2 13B  |  Context: 4K
RAM (INT4): ~9–10GB  |  Ollama tag: nous-hermes2:13b

Noticeably better reasoning and writing quality than the 7B. The 4K context window is a real limitation for long documents. Best for users with 16GB RAM who want improved quality without going to 34B.

Power User

Nous Hermes 2 Yi 34B

Base: Yi 34B  |  Context: 200K
RAM (INT4): ~22–24GB  |  Ollama tag: nous-hermes2-yi-34b

The flagship. Yi 34B's enormous context window combined with Nous fine-tuning makes this exceptional for long-document analysis. Requires significant RAM — 32GB+ recommended. Approaches GPT-3.5 territory on reasoning benchmarks.

Specialized

Nous Hermes 2 Mixtral 8×7B

Base: Mixtral MoE  |  Context: 32K
RAM (INT4): ~28–30GB  |  Ollama tag: nous-hermes2-mixtral

Mixture-of-Experts architecture — inference activates only 2 of 8 expert layers per token, giving near-13B inference cost with near-70B quality on some tasks. Needs 32GB RAM. Worth it for users who have the hardware.

Understanding the Alignment Approach

One of the most common questions about Nous Hermes 2 is where it sits on the spectrum between "refuses everything" and "no guardrails at all." The answer matters for legitimate professional use cases.

Nous Hermes 2 lands in a deliberate middle zone. It will discuss security topics, legal gray areas, mature content in appropriate contexts, and competitive intelligence without the reflexive hedging ChatGPT applies. It will not assist with clearly harmful requests. The Nous team describes this as "not treating users like children while still having a conscience."

For most professional use cases — writing, research, analysis, coding, summarization — the alignment difference from ChatGPT is invisible. You only notice it when you're doing work that triggers ChatGPT's overly cautious filters: security research, competitive analysis, medical professional queries, fiction with mature themes, or frank discussion of controversial topics.

⚠️
Not a replacement for Dolphin or fully uncensored models

If your use case specifically requires a model with all RLHF constraints removed, Nous Hermes 2 is not that model. It has alignment — it's just more calibrated than ChatGPT's. For genuinely unconstrained inference, see the Dolphin page. For most users, Nous Hermes 2's balance is actually preferable: useful without requiring constant jailbreaking, reliable without excessive refusals.

Honest Strengths and Weaknesses

✓ Real Strengths

  • MT-Bench scores consistently beat official Llama/Mistral fine-tunes at same size
  • Alignment calibrated for professional use — fewer false refusals
  • Apache 2.0 on all variants — full commercial use
  • ChatML prompt format is widely supported across tooling

  • No official API — community support only

Deployment: Ollama Quickstart

The fastest path to running Nous Hermes 2 is via Ollama. All four major variants are available in the Ollama library. See our Quickstart guide for Ollama installation instructions.

bash — Ollama 
# 7B — default, runs on 8GB RAM
ollama run nous-hermes2

# 13B — better quality, needs ~16GB RAM
ollama run nous-hermes2:13b

# 34B Yi — long context flagship, needs ~32GB RAM
ollama run nous-hermes2-yi-34b

# Mixtral MoE — needs ~32GB RAM, high quality
ollama run nous-hermes2-mixtral

ChatML Prompt Format

Nous Hermes 2 uses the ChatML format — the same format used by OpenAI's API. This is a significant practical advantage: any code written for the OpenAI API needs minimal changes to work with Nous Hermes 2 via an Ollama-backed OpenAI-compatible endpoint.

ChatML Format — Nous Hermes 2
<|im_start|>system
You are a helpful AI assistant specialized in data privacy law.<|im_end|>
<|im_start|>user
What are the key differences between GDPR and CCPA?<|im_end|>
<|im_start|>assistant
python — Python with Ollama REST API chat.py 
import requests, json

OLLAMA_URL = "http://localhost:11434/api/chat"

def chat(messages: list, model: str = "nous-hermes2") -> str:
    payload = {
        "model": model,
        "messages": messages,
        "stream": False,
        "options": {
            "temperature": 0.7,
            "num_ctx": 8192,
        }
    }
    r = requests.post(OLLAMA_URL, json=payload)
    r.raise_for_status()
    return r.json()["message"]["content"]

# Example: privacy policy analysis
messages = [
    {
        "role": "system",
        "content": "You are an expert in data privacy compliance."
    },
    {
        "role": "user",
        "content": "Summarize the user rights under GDPR in plain English."
    }
]

response = chat(messages)
print(response)

OpenAI-compatible endpoint via Ollama

Ollama exposes an OpenAI-compatible endpoint at http://localhost:11434/v1/chat/completions. Set your OpenAI client's base_url to that address and model to nous-hermes2 — no other code changes needed. This makes Nous Hermes 2 a near-seamless drop-in for ChatGPT in existing applications.

Getting the Most Out of Nous Hermes 2

Nous Hermes 2 responds well to specific system prompts. Unlike ChatGPT, where system prompts are often overridden by safety layers, the system prompt in Nous Hermes 2 is genuinely authoritative — the model takes it seriously throughout the conversation.

Effective System Prompt Patterns

For Professional / Domain Expert Use
You are an expert [domain] professional assisting [role description].
Provide direct, detailed responses. Assume the user has professional
background in this field. Avoid excessive disclaimers.
For Document Analysis (34B)
You are a careful document analyst. When given documents, extract
key information accurately. Cite specific sections when making claims.
If information is absent from the document, say so explicitly rather
than inferring.
For Structured Output
You are a structured data extraction assistant. Always respond with
valid JSON matching the schema provided by the user. Do not include
explanatory text outside the JSON object.
💡
Temperature guidance

For factual analysis and document work, use temperature: 0.3–0.5. For creative writing and brainstorming, 0.7–0.9 produces more varied and interesting outputs. Nous Hermes 2 is more sensitive to temperature settings than many other models — the difference between 0.3 and 0.8 is noticeable.
