What Is Dolphin?

Dolphin is a series of fine-tuned language models created by Eric Hartford under the Cognitive Computations project. The models are built on top of base weights from Mistral, Mixtral, and Llama, with the current flagship being Dolphin 2.9 on Mistral 7B. Dolphin is available on Ollama and Hugging Face under Apache 2.0 licensing.

What separates Dolphin from most models in the same parameter range is straightforward: the RLHF alignment layer has been deliberately removed. Most consumer-facing AI models — ChatGPT, Claude, Gemini — go through a post-training process where human raters reward certain outputs and penalize others, producing a model that refuses requests, adds unsolicited disclaimers, and declines to engage with content the company considers liability-adjacent. Dolphin skips that process. The model tries to do what you ask.

This is not the same as a model trained to cause harm. It is a capable instruction-following model with no corporate refusal layer sitting on top of it. The distinction matters, and it is worth understanding before deploying.

The Dolphin Model Family

Dolphin 2.9 Mistral 7B

7B Parameters

The practical starting point. Runs on 8GB RAM with no GPU required. Strong instruction following, 32K context window, and fast enough for interactive use on modest hardware. The right choice for most individual deployments.

Dolphin 2.9 Mixtral 8x7B

8x7B MoE

Mixture-of-Experts architecture with significantly stronger reasoning than the 7B variant. Requires 48GB RAM or 24GB+ VRAM. Better for complex multi-step tasks, long document analysis, and use cases where the 7B hits its reasoning ceiling.

Dolphin 2.9 Llama 3

8B Parameters

Dolphin fine-tune on Meta's Llama 3 base. Benefits from Llama 3's improved tokenizer and training data while retaining Dolphin's uncensored instruction-following behavior. A strong alternative to the Mistral base for general use.

Dolphin Phi-3

3.8B Parameters

Dolphin applied to Microsoft's Phi-3 Mini base. Exceptionally lightweight — runs comfortably on 4GB RAM. Reduced reasoning capability compared to 7B variants, but viable for edge deployments and low-resource environments.

GPT-4o leads on raw benchmark scores — that is not in dispute. For complex reasoning chains, multi-step coding problems, and tasks that require broad world knowledge, it outperforms Dolphin 2.9 at any parameter size currently available via Ollama.

Where Dolphin wins is compliance — not regulatory compliance, but task compliance. It does what you ask. For many production workflows, a model that executes instructions without negotiating is more useful than a smarter model that stops to question whether you should be doing this. That trade-off is real and worth making deliberately.

Who Uses Dolphin

Fiction Writers

Dark themes, morally complex characters, villain dialogue, and mature content that consumer AI models refuse to engage with. Dolphin treats creative writing as creative writing.

Security Researchers

Red-teaming, vulnerability research, and AI safety testing that requires a model willing to engage with adversarial prompts without deflecting. Useful for evaluating guardrail robustness in other systems.

Developers and Tooling

Internal automation pipelines where refusals create workflow failures. A model that reliably executes instructions is easier to build on than one that introduces unpredictable refusal behavior.

Researchers and Academics

Historical atrocities, extremist ideologies, sensitive social topics, and other subjects where understanding requires engaging with uncomfortable material directly.

Privacy-First Users

People who want both zero data exfiltration and zero behavioral guardrails. Local deployment via Ollama satisfies both requirements simultaneously.

Enterprise Internal Tooling

Organizations running internal knowledge bases, document processing, or support tooling where content filter false positives disrupt operations and cannot be individually overridden.

Deploying Dolphin via Ollama

# Pull Dolphin 2.9 on Mistral 7B — recommended starting point
ollama pull dolphin-mistral

# Pull Dolphin on Llama 3
ollama pull dolphin-llama3

# Run interactively
ollama run dolphin-mistral

# Serve with OpenWebUI for a full chat interface
docker run -d -p 3000:8080 \
  -e OLLAMA_BASE_URL=http://localhost:11434 \

The Responsible Use Note

Dolphin runs locally. No one is watching. The model will not refuse most requests.

That means you are the guardrail. The RLHF layer that consumer AI companies install is not a moral authority — it is a liability management tool. Removing it transfers responsibility back to the person running the model. Most people using Dolphin are writers, developers, and researchers with entirely ordinary needs. The use cases above are representative of the actual user base, not the edge cases that get attention in press coverage.

Use it for things that make sense. That is the whole note.

Deployment Context Matters

If you are deploying Dolphin as a shared service — an internal chatbot, a customer-facing tool, or any multi-user environment — you are responsible for implementing appropriate access controls and use policies. An uncensored model exposed to untrusted users without additional guardrails is a different risk profile than a single-user local deployment. Build accordingly.
