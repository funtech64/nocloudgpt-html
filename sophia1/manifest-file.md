# NoCloudGPT Model Family Manifest

This manifest is the working list of remaining model families that need the updated NoCloudGPT model-family treatment.

The purpose is not just to create an Ollama encyclopedia. Each model-family page should help the reader understand whether that model is useful for private AI deployment through NoCloudGPT.

## Standard Treatment for Each Model Family

Each target family should receive:

- a family landing page
- buyer-focused use-case copy
- plain-English strengths and limitations
- licensing section with official source links
- available model sizes / Ollama tags table
- recommended NoCloudGPT tier or AI Power Level
- CTA path to quote or deployment page
- no unsupported benchmark claims
- no fake GitHub commit claims

## Production Directory

Default production target:

`/models/`

This repository now uses `/models/` as the production catalog path. Do not generate legacy menu-path pages.
