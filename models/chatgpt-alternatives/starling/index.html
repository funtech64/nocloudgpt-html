Training a good chat model normally requires thousands of human preference labels — expensive, slow, and hard to scale. What Makes Starling Different: RLAIF

Most instruction-tuned models — including ChatGPT — use Reinforcement Learning from Human Feedback (RLHF). Human annotators compare pairs of model responses and indicate which is better. This preference signal trains a reward model, which then guides further fine-tuning. The process works well but has a hard constraint: it scales with human labour.

Starling uses Reinforcement Learning from AI Feedback (RLAIF): GPT-4 acts as the preference annotator instead of humans. The Berkeley team created the Nectar dataset — 183,000 chat prompts, each with seven different model responses ranked by GPT-4. This is roughly the same scale as the data used to train Llama 2 Chat 70B's RLHF stage, produced in days rather than months.

The Nectar Dataset

Starling's RLAIF training depends entirely on Nectar — a preference dataset that Berkeley also open-sourced under Apache 2.0. Understanding Nectar explains both Starling's strengths and its characteristic quirks.

How Nectar was built

🍯 Nectar Dataset Construction Pipeline

1
Data sourcing

Aggregate diverse chat prompts

Collected 183,000 chat prompts from multiple public datasets: ShareGPT, Anthropic HH, OpenAssistant, FLAN, and others. Diversity was intentional — topic range, prompt length, difficulty level, and task type were all sampled broadly to prevent the reward model from overfitting to a narrow domain.

2
Response generation

Generate 7 responses per prompt from different models

Each prompt was sent to seven different language models to generate candidate responses: GPT-4, GPT-3.5-turbo, Claude, Llama 2 variants, Mistral, and others. This created response diversity across quality levels — essential for the reward model to learn a meaningful quality gradient rather than just "good vs bad."

3
AI annotation

GPT-4 ranks all 7 responses per prompt

GPT-4 was prompted to rank the seven candidate responses from best to worst for each prompt. Rather than pairwise comparisons (which require O(n²) API calls), ranking all seven at once is more efficient and gives finer-grained signal. The ranking is converted into preference pairs for reward model training.

4
Reward model training

Train PairRM on the preference rankings

The GPT-4 rankings are used to train PairRM — Berkeley's open-source reward model, also released under Apache 2.0. PairRM learns to score responses according to the GPT-4-annotated quality signal. PairRM is available separately and can be reused for other RLAIF projects.

5
Policy fine-tuning

Fine-tune OpenChat 3.5 using PairRM reward signal

OpenChat 3.5 (itself a Mistral 7B fine-tune) is further trained using the PairRM reward model to guide PPO/DPO optimisation. Starling inherits OpenChat 3.5's C-RLFT instruction-following capability and adds preference alignment on top — a two-stage approach that compounds both improvements.

🍯
The Nectar dataset is independently valuable

Because Berkeley released Nectar separately under Apache 2.0, it's become a reference dataset for RLAIF research. If you want to experiment with reward model training or preference alignment on your own base model, Nectar provides a freely usable preference signal without any data collection overhead. The PairRM reward model is also usable as a quality evaluator for other models' outputs.

⚠️
MT-Bench is judged by GPT-4 — and Starling was trained on GPT-4 preferences

Starling's 8.09 MT-Bench score is legitimately impressive for a 7B model, but there's an important methodological note: MT-Bench is evaluated by GPT-4, and Starling was trained to produce responses that GPT-4 prefers. The model has, in effect, been optimised for the evaluation metric. This doesn't invalidate the result — GPT-4 preference does correlate with human preference in most domains — but it means the score should be read as "highly optimised for GPT-4-style quality" rather than "objectively best 7B model for all use cases."

💡
Hardware requirements

Starling 7B requires 5–6GB RAM with INT4/Q4 quantisation — one of the most efficient footprints in this guide. It runs comfortably on any system with 8GB unified memory, including entry-level M1/M2 MacBooks and mid-range Windows laptops. See deployment quickstart for Ollama setup on your platform.

Prompt Format

Starling inherits OpenChat 3.5's GPT4-corrected (ChatML-like) prompt format. Most inference frameworks detect and apply this automatically when running the GGUF versions.

text — Starling prompt format 
GPT4 Correct User: {user_message}<|end_of_turn|>GPT4 Correct Assistant:
text — Multi-turn format 
GPT4 Correct User: {first_user_message}<|end_of_turn|>GPT4 Correct Assistant: {first_assistant_response}<|end_of_turn|>GPT4 Correct User: {second_user_message}<|end_of_turn|>GPT4 Correct Assistant:
⚠️
Prompt format matters for Starling

Starling is sensitive to prompt formatting in a way that general-purpose models like Llama 3 Instruct are not. Using an incorrect template (e.g., ChatML <|im_start|> style instead of the GPT4-corrected format) noticeably degrades response quality. If you're using llama.cpp or a local inference server, verify the template is set correctly. Ollama handles this automatically.

Honest Assessment

✓ Real Strengths

  • Highest MT-Bench score for any 7B model at its release date
  • Apache 2.0 — fully commercial, weights and data
  • Nectar and PairRM released openly — whole pipeline is reproducible
  • Strong multi-turn conversation quality
  • 5–6GB RAM — runs on budget hardware
  • 8K context window — double Orca 2's limit
  • Naturally explanatory style; good for tutoring/documentation use cases
  • Well-supported in Ollama

✗ Real Limitations

  • GPT-4 scoring bias: optimised for GPT-4 evaluator preferences
  • Prone to verbose responses — GPT-4 tends to prefer longer answers
  • Average reasoning and math — not purpose-built for structured tasks
  • Average code generation; use a code-specific model for dev tasks
  • Only available in 7B — no larger variant
  • No updates since November 2023; newer 7B models have surpassed it overall
  • Slight sensitivity to prompt format degradation
