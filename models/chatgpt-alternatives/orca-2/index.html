Orca 2: Teaching Models
When to Use Which Reasoning

Orca 1 taught small models to reason step-by-step. Orca 2 asks a harder question: what if chain-of-thought isn't always the right strategy? Cautious reasoning teaches the model to select the optimal approach per task — direct answer, step-by-step, recall from memory, or delegation — matching or beating models 5× its size on reasoning benchmarks.

From Explanation Tuning to Cautious Reasoning

Orca 1 established that training on GPT-4's reasoning traces — not just its answers — produces significantly better generalisation at small model sizes. The finding was clean: explanation tuning beats imitation learning, even at a 5× parameter disadvantage.

Orca 2 starts from a different observation: GPT-4 doesn't use chain-of-thought reasoning on every task. When you ask it what the capital of France is, it doesn't laboriously reason through the problem — it just answers. When you ask it to solve a complex math proof, it does reason step-by-step. The reasoning strategy is task-dependent.

Small models trained with standard explanation tuning tend to over-apply chain-of-thought — producing verbose reasoning traces even for tasks where a direct answer would be better. This wastes tokens, slows inference, and can actually reduce accuracy on recall tasks where the model second-guesses itself mid-trace. Orca 2's solution: teach the model to select the right strategy first.

The Four Reasoning Strategies

Orca 2 is trained to recognise which of four reasoning strategies is appropriate for a given input, and to apply that strategy rather than defaulting to chain-of-thought for everything.

⚡

Direct Answer

For tasks where the answer is unambiguous and reasoning adds no value. Used when overthinking would introduce errors.

"What is 7 × 8?" → "56" — not five paragraphs about multiplication.
🧠

Recall from Memory

For factual lookups where the answer exists in training data as a stored fact. No derivation needed.

"Who wrote Hamlet?" → "William Shakespeare" — retrieve, don't derive.
🔗

Chain-of-Thought

For genuinely complex multi-step problems where intermediate reasoning steps are necessary for correctness.

"If a train leaves Chicago at 9am travelling at 60mph and another leaves at 10am at 80mph, when do they meet?"
🤝

Delegation

For tasks outside the model's reliable competence — acknowledge the limit, suggest alternatives or request clarification.

"Translate this medical report into clinical Japanese" → acknowledge specialisation limits rather than hallucinate.
🔬
Why strategy selection matters for accuracy

Counter-intuitively, chain-of-thought can reduce accuracy on recall tasks. If a model knows that Paris is the capital of France, but it's been trained to always produce reasoning traces, it might generate intermediate reasoning steps like "France is a European country, its government is located in..." that introduce opportunities for error. Direct retrieval is more reliable for high-confidence factual recall. Orca 2's cautious reasoning framework explicitly addresses this failure mode.

The 70B comparison result

Orca 2 13B matches or exceeds Llama 2 Chat 70B on AGIEval and BigBench Hard — models with more than 5× the parameters. This is the paper's headline claim, and it holds up on the specific benchmarks tested. It does not hold universally: Llama 2 70B outperforms Orca 2 13B on general conversation quality (MT-Bench) and creative tasks. The advantage is specific to structured reasoning.

Running Orca 2 Locally

Ollama (Recommended)

Orca 2 has official Ollama support, making it the easiest Orca variant to run locally for research and experimentation.

bash — Ollama 
# Pull and run Orca 2 (13B by default)
ollama run orca2

# Explicitly select 7B for lower RAM usage
ollama run orca2:7b

# 13B variant explicitly
ollama run orca2:13b
💡
Hardware requirements via Ollama

Orca 2 7B: 5–6GB RAM recommended (INT4). Runs on most modern laptops with 8GB unified memory.
Orca 2 13B: 8–10GB RAM recommended. Comfortable on 16GB systems; possible on 8GB with swap at reduced speed. See the deployment quickstart for platform-specific setup.

Eliciting Cautious Reasoning Explicitly

text — System prompts for different strategy modes 
# For reasoning tasks — encourage explicit strategy selection
You are Orca, a helpful AI assistant. Before answering, 
identify whether this question requires step-by-step reasoning, 
direct recall, or a simpler approach. Use the appropriate 
strategy rather than always showing your work.

# For structured analysis tasks
You are Orca, a helpful AI assistant. For complex problems,
break them into clear sub-steps and verify each before proceeding.
For simple factual questions, answer directly without unnecessary elaboration.

# For educational use — always show reasoning
You are Orca, a helpful AI assistant working as a tutor.
Always explain your reasoning step-by-step, even for simple problems,
so the student can understand the method.
🔬
Strategy selection is implicit, not a separate call

Unlike an agent framework where you'd explicitly route to different reasoning modules, Orca 2's strategy selection is baked into the model weights during training. The model implicitly classifies the task type and generates output appropriate to that type — you don't need to build routing logic yourself. The system prompt can nudge this behaviour but doesn't control it absolutely.

Using with Ollama's Python API

python — ollama library 
import ollama

# Simple reasoning query
response = ollama.chat(
    model='orca2:13b',
    messages=[
        {
            'role': 'system',
            'content': 'You are Orca, a helpful AI assistant. Select the appropriate reasoning strategy for each task.'
        },
        {
            'role': 'user',
            'content': 'A company has 480 employees. After a merger, the workforce grows by 35% then shrinks by 20%. What is the final headcount?'
        }
    ]
)

print(response['message']['content'])

Honest Assessment

✓ Real Strengths

  • Best reasoning benchmarks at the 7B–13B scale as of its release
  • Strategy selection avoids over-verbose reasoning on simple tasks
  • Official Ollama support — trivial to run locally
  • Llama 2 base is more permissive than LLaMA 1
  • 7B variant competitive with much larger models on reasoning
  • Clear improvement over both Orca 1 and Llama 2 Chat on benchmarks
  • ChatML format — integrates cleanly with standard tooling

✗ Real Limitations

  • Non-commercial license blocks production deployment
  • 4K context window — severely limiting for document tasks
  • Llama 2 base is dated; Llama 3.x models show significantly better results
  • Average general conversation quality; reasoning-optimised only
  • Strategy routing isn't perfect — occasionally overthinks simple questions
  • No code-specialised variant
  • Not updated since November 2023
