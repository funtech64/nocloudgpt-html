WizardLM: Evol-Instruct and the
Complexity Problem

Most instruction-tuned models are trained on human-written prompts — which cluster around simple, common requests. WizardLM asked a different question: what if you used an LLM to automatically rewrite those instructions into progressively more complex variants, then trained on the harder versions? The result was a model that outperformed ChatGPT on complex instruction-following tasks despite being a fraction of the size. Run it locally — no cloud, no API fees, no data leaving your machine.

Evol-Instruct: The Core Innovation

The central insight behind WizardLM is that the complexity distribution of human-written instructions is heavily skewed toward simple tasks. When you train only on those, you get a model that handles easy requests well but struggles with multi-step, technically demanding prompts. Evol-Instruct solves this by using an LLM (GPT-4 in the original research) to automatically transform simple instructions into harder variants through a defined evolution process.

Step 1
Seed Instructions
Start with a set of relatively simple human-written instructions — similar to the Alpaca 52K dataset.
Step 2
In-Depth Evolution
Rewrite each instruction to be more complex: add constraints, increase reasoning steps, require domain expertise, or deepen specificity.
Step 3
In-Breadth Evolution
Generate entirely new instructions that cover different topics — expanding coverage rather than deepening existing ones.
Step 4
Filter & Score
Remove evolutions that are too similar to the seed, too short, or that the LLM refuses to answer. Keep only substantive improvements.
Step 5
Repeat (5 rounds)
Apply evolution repeatedly. After 5 rounds, the 52K seed becomes ~250K instruction pairs spanning a wide complexity range.

The key result: models trained on the Evol-Instruct dataset outperform models trained on the original simple instructions on complex tasks, even when total training data volume is similar. The difficulty distribution of training data matters as much as its volume.

🧙
Why this matters for local use

If you are running a 7B model locally and need it to handle genuinely complex tasks — multi-step code generation, structured analysis, technical writing with specific constraints — WizardLM's training approach gives it an edge over comparably-sized models trained on simpler instruction sets. You get more reasoning capability per parameter than a naive fine-tune.

Version History

May 2023
WizardLM 7B v1.0
First release. Fine-tuned Llama 1 (7B) on 250K Evol-Instruct pairs. Demonstrated that evolved instructions produce better complex-task performance than simple instruction sets. Showed 88.3% win rate over ChatGPT on complex instructions in human evaluation.
June 2023
WizardLM 13B v1.1 + 30B
Extended to larger Llama 1 bases. 30B variant competitive with early GPT-4 on structured task benchmarks. Evol-Instruct refined to include more code-focused evolutions.
August 2023
WizardLM 70B v1.0 (Llama 2)
Rebased on Llama 2. 70B variant achieves strong scores on TruthfulQA, MMLU, and HumanEval. The 70B is the last version to use Llama 2 for the largest size. Context window: 4K.
October 2023
WizardCoder Python 34B
Specialised code variant using Code Llama 34B as base. Achieves 73.2% on HumanEval — briefly the best-performing open-source code model at that size. This is a separate model family from chat-focused WizardLM.
April 2024
WizardLM-2 (8x22B, 70B, 7B) ★ Current
Major architecture shift. Uses Mistral 7B (7B variant) and Mixtral 8x22B (largest variant) as bases instead of Llama. Context extended to 32K. Competitive with GPT-4 on several benchmarks. The 7B variant scores 8.01 on MT-Bench. Note: Microsoft briefly withdrew WizardLM-2 from release for safety review before reposting. Mistral-based variants have more permissive licensing.

ℹ️
WizardLM-2 7B vs Llama 3.1 8B in 2025

WizardLM-2 7B was released in April 2024 and scores 8.01 on MT-Bench — impressive for its size. However, Llama 3.1 8B Instruct (July 2024) scores 8.22 and offers a 128K context window, broader language support, and a more permissive licence. For most new deployments in 2025, Llama 3.1 8B is the stronger default. WizardLM-2 7B remains relevant if you specifically want the Evol-Instruct training methodology's characteristics on complex instruction tasks, or if you are already using Mistral-family models and want consistency.

Where WizardLM Excels

🔢

Multi-step reasoning

Tasks requiring sequential reasoning steps: "Given X, derive Y, then use Y to evaluate Z under constraints A and B." The Evol-Instruct training specifically targets this pattern.

📐

Constrained instruction following

Instructions with multiple simultaneous constraints: format requirements, content restrictions, length limits, and specific terminology — all honoured together.

💻

Technical writing with requirements

Documentation, specifications, and technical content where you provide detailed requirements and expect them to be fully addressed — not just partially.

🧩

Structured data tasks

Generating JSON, YAML, or other structured output that must conform to a schema. WizardLM handles format constraints well due to diversity of evolved training examples.

📊

Analysis tasks

Breaking down a complex problem, examining it from multiple angles, and providing a structured conclusion. The model was specifically trained on this instruction pattern.

🔬

Research assistance

Summarising literature, identifying gaps in arguments, comparing multiple sources against a set of criteria. Benefits from the model's exposure to expert-level instruction patterns.

Running WizardLM Locally

Via Ollama (recommended)

bash — Ollama 
# Install Ollama first: https://ollama.com

# WizardLM-2 7B — recommended starting point
ollama pull wizardlm2:7b

# WizardLM-2 8x22B — requires ~80GB RAM (MoE architecture)
ollama pull wizardlm2:8x22b

# Start a chat session
ollama run wizardlm2:7b

Python API via Ollama

python — Ollama Python client 
import ollama

# WizardLM-2 handles complex, multi-part instructions well
response = ollama.chat(
    model='wizardlm2:7b',
    messages=[{
        'role': 'user',
        'content': """Analyse the following business scenario and provide:
1. A SWOT analysis in a 2x2 grid (use ASCII art)
2. Three strategic recommendations, each with:
   - The recommendation (max 20 words)
   - Rationale (2-3 sentences)
   - Key risk and mitigation
   - Success metric
3. A prioritisation matrix ranking the recommendations by 
   impact vs implementation difficulty

Scenario: A regional law firm with 50 lawyers is considering 
launching an AI-assisted contract review service for SMEs."""
    }]
)

print(response['message']['content'])

OpenAI-compatible API

python — OpenAI-compatible (Ollama serves on port 11434) 
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:11434/v1",
    api_key="ollama"
)

# System prompt tuning for WizardLM-2
response = client.chat.completions.create(
    model="wizardlm2:7b",
    messages=[
        {
            "role": "system",
            "content": "You are a precise technical assistant. Follow all instructions exactly. When given a numbered list of requirements, address each one explicitly and in order."
        },
        {
            "role": "user",
            "content": "Your instruction here..."
        }
    ],
    temperature=0.7
)

print(response.choices[0].message.content)

Getting the Best from WizardLM-2

Use numbered requirements

WizardLM-2 was trained on instructions with explicit numbered constraints. When you have multiple requirements, list them explicitly rather than embedding them in prose. The model is more likely to address each requirement in turn.

prompt — numbered requirements pattern 
# Less effective:
"Write a short product description for a standing desk 
that mentions the height range and is suitable for LinkedIn."

# More effective (mirrors Evol-Instruct patterns):
"Write a product description for an adjustable standing desk. 
Requirements:
1. Length: exactly 80–100 words
2. Must include: height range (65–130 cm), 
   electric motor speed, and warranty period (5 years)
3. Tone: professional but approachable; suitable for LinkedIn
4. End with a single call-to-action sentence
5. Do not use the words 'innovative' or 'revolutionary'"

Specify output structure explicitly

prompt — structured output 
"Evaluate the following argument for logical consistency. 
Return your response as valid JSON with this exact structure:
{
  'verdict': 'valid' | 'invalid' | 'partially_valid',
  'premises': [{'claim': str, 'sound': bool, 'note': str}],
  'logical_gaps': [str],
  'overall_score': int (1-10),
  'one_line_summary': str
}

Argument: [paste argument here]"

Honest Assessment

✓ Genuine Strengths

  • Evol-Instruct training genuinely improves complex instruction handling vs naive fine-tunes
  • WizardLM-2 7B scores 8.01 MT-Bench — strong for its size class
  • 32K context in WizardLM-2 (up from 4K in v1)
  • Mistral-based WizardLM-2 variants under Apache 2.0
  • Handles simultaneous constraints better than many comparable models
  • WizardCoder variants strong for code tasks
  • Available via Ollama — simple local deployment
  • Active research lineage — Evol-Instruct concepts adopted widely

✗ Real Limitations

  • Llama 2-based variants (most sizes) are non-commercial
  • Superseded in overall benchmarks by Llama 3.1 8B for most use cases
  • WizardLM-2 was briefly withdrawn for safety review — history worth noting
  • 4K context in older versions is very limiting
  • 70B and 8x22B variants require substantial hardware (40–80GB RAM)
  • Less active development compared to Llama 3 or Mistral families in 2025
  • Evol-Instruct data generated by GPT-4 — inherits any biases or errors from that process
  • Not designed for multilingual use; primarily English
