# NoCloudGPT — Complete Artwork Sources Manifest (All Models)

**Purpose**  
This is the single source of truth for all model family artwork in the `/models/` directory.  
It lists every model family folder that currently exists and provides the best available reference links for downloading artwork.

**Rules**
- Place all images inside the correct folder: `/models/<family-slug>/`
- Recommended filenames: `hero.webp`, `card.webp`, `sidebar.webp`, `og.webp`, `brand.webp`
- Prefer images from official sources or high-quality stock when possible.
- Always check `https://ollama.com/library` for the model family first (many have nice model cards or banners).
- Do **not** imply official partnership with any developer or company.
- Use `VERIFY:` comments in HTML when licensing is uncertain.
- Never hotlink images in production without proper review.

---

## Image Naming Convention (Use Exactly These)

| Purpose          | Filename          | Recommended Size     | Placement                     |
|------------------|-------------------|----------------------|-------------------------------|
| Hero             | `hero.webp`       | 1200×600 / 1280×720  | Top of family page            |
| Card / Grid      | `card.webp`       | 800×450              | Sidebar cards, index grids    |
| Sidebar          | `sidebar.webp`    | 400×300 / 600×400    | Right sidebar                 |
| Social / OG      | `og.webp`         | 1200×630             | Open Graph / social sharing   |
| Brand / Logo     | `brand.webp`      | 320×80 or 400×120    | Developer attribution         |

## How to Use This File with Cursor

1. Ask Cursor to read `models/artwork-sources.md`.
2. Tell it to process families in batches (start with High Priority).
3. Instruct it to:
   - Check `https://ollama.com/library/<family>` first for existing artwork.
   - Download appropriate images into `/models/<family-slug>/`.
   - Use the exact filenames from the naming convention table.
   - Add or update the “Artwork and source references” section.
   - Update `<img>` tags to use local paths.
