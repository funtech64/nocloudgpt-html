1. What Is Bespoke-Minicheck?

Bespoke-Minicheck is a purpose-built natural language inference (NLI) model designed to solve one of the most commercially damaging problems in deployed AI systems: hallucination. When large language models generate text, they sometimes produce plausible-sounding statements that are factually incorrect or not supported by any source material. In customer-facing or compliance-critical environments, this is not merely inconvenient — it is a liability.

Unlike general-purpose LLMs that can be prompted to "check themselves," Bespoke-Minicheck is a specialist verification model. It takes two inputs — a source document and a generated claim — and outputs a single binary classification: supported or unsupported. This deterministic, auditable output makes it suitable as a post-generation filter inside RAG pipelines, document Q&A systems, summarization workflows, and automated report generation tools.

Developed by Bespoke Labs, Minicheck was benchmarked on the LLM-AggreFact benchmark — a comprehensive fact-checking evaluation suite — and achieved state-of-the-art performance among models of comparable size, outperforming much larger models on grounded factual verification tasks.

2. How It Works

Bespoke-Minicheck operates as a binary NLI classifier. The model is fine-tuned on large-scale fact-checking datasets and trained to answer a single question: "Is this claim supported by this document?"

The Verification Pipeline

In a typical deployment, Bespoke-Minicheck sits as a post-generation layer in a larger workflow:

  1. Retrieval: A RAG system retrieves relevant document chunks from a vector store.
  2. Generation: A primary LLM (e.g., Llama 3, Mistral, Gemma) generates a response grounded in those chunks.
  3. Verification: Bespoke-Minicheck receives each generated sentence (or claim) alongside the source chunk and classifies it as supported or unsupported.
  4. Filtering / Flagging: Unsupported claims are either removed, flagged for human review, or trigger a regeneration request.

Model Architecture

Bespoke-Minicheck uses a compact transformer encoder architecture fine-tuned specifically for entailment classification. It is not an autoregressive text generator — it does not produce open-ended text — which makes it significantly faster and more resource-efficient than using a full generative LLM for the same verification task.

The model operates at the sentence or paragraph level. For long-form document verification, claims can be split into individual sentences and each verified independently, producing a granular, sentence-level confidence map of the generated output.

Why not just prompt GPT to check itself? Self-verification via prompting is unreliable — LLMs are prone to confirming their own hallucinations. Bespoke-Minicheck is a separate, dedicated model trained exclusively on verification data, making its outputs far more trustworthy and consistent than self-critique approaches.

Scoring Output

The model outputs a probability score between 0 and 1 for the "supported" class. Organizations can set their own confidence threshold — for example, flagging any claim scoring below 0.75 for human review, or rejecting any claim below 0.5 from automated outputs. This tuneable threshold allows teams to balance precision and recall based on their specific risk tolerance.

3. Ideal Applications

Bespoke-Minicheck's narrow, deterministic purpose makes it exceptionally useful across a wide range of industries where AI-generated text must be trusted, audited, or compliant with regulatory standards. Below are the highest-value deployment scenarios.

⚖️

Legal Document Q&A

Law firms and legal operations teams use AI to extract answers from contracts, case files, and regulatory documents. Bespoke-Minicheck acts as a grounding layer, verifying that every extracted answer is genuinely present in the cited document — critical for avoiding professional liability from AI-generated misstatements.

🏥

Clinical Knowledge Assistants

Healthcare organizations deploying AI assistants for clinical decision support or patient communication need verification that generated responses align with approved clinical guidelines, formularies, or patient records. Bespoke-Minicheck provides an auditable safety net before any AI-generated clinical text is presented to staff or patients.

📊

Financial Report Summarization

Investment research, earnings summaries, and regulatory filings generated or summarized by AI must be factually grounded. A single hallucinated revenue figure or misattributed forecast can create significant compliance and reputational risk. Minicheck provides sentence-level verification against source financial documents.

📰

Automated News & Content Monitoring

Media organizations and brand monitoring teams using AI to synthesize news summaries or generate content briefs can use Minicheck to flag any claims in AI output that cannot be traced back to verified source articles — reducing the risk of publishing AI-generated inaccuracies.

🔬

Scientific & Research Assistants

Research institutions using AI to help scientists survey literature, draft grant applications, or summarize experimental results can use Minicheck to verify that every cited finding is genuinely present in the referenced paper — preventing fabricated citations, a known failure mode of general LLMs.

🛡️

RAG Pipeline Quality Assurance

Any organization running a retrieval-augmented generation pipeline — internal knowledge bases, product documentation Q&A, HR policy assistants — can integrate Minicheck as an automated QA layer that continuously monitors output quality and flags generative drift before it reaches end users.

🏛️

Government & Public Sector

Government agencies producing AI-assisted policy documents, public communications, or citizen service responses must ensure outputs are grounded in official policy sources. Minicheck supports EU AI Act compliance requirements around transparency and factual accuracy in high-risk AI applications.

🎓

Educational Content Platforms

EdTech platforms using AI tutors or content generators need to ensure that explanations, quiz answers, and study materials are factually consistent with their curriculum sources. Minicheck can verify AI-generated educational content against approved textbooks or learning standards before delivery.

import requests import json def verify_claim(document: str, claim: str, threshold: float = 0.75) -> dict: prompt = f"""Document: {document} Claim: {claim} Is this claim fully supported by the document above? Answer with only: SUPPORTED or UNSUPPORTED, then explain briefly.""" response = requests.post( "http://localhost:11434/api/generate", json={ "model": "bespoke-minicheck", "prompt": prompt, "stream": False } ) result = response.json() answer = result["response"].strip() supported = answer.upper().startswith("SUPPORTED") return { "claim": claim, "supported": supported, "explanation": answer } # Example usage doc = "NoCloudGPT deploys AI models on dedicated infrastructure with zero data egress." claim = "NoCloudGPT sends user data to third-party cloud providers." result = verify_claim(doc, claim) print(result) # {'claim': '...', 'supported': False, 'explanation': 'UNSUPPORTED — ...'}

Batch Verification Pipeline

import requests from typing import List, Dict def batch_verify(document: str, claims: List[str]) -> List[Dict]: """Verify multiple claims against a single source document.""" results = [] for claim in claims: result = verify_claim(document, claim) results.append(result) supported_count = sum(1 for r in results if r["supported"]) return { "total_claims": len(claims), "supported": supported_count, "unsupported": len(claims) - supported_count, "grounding_score": supported_count / len(claims), "details": results }

8. Frequently Asked Questions

What is Bespoke-Minicheck best used for?

Bespoke-Minicheck is best used as a post-generation verification layer in RAG pipelines, document Q&A systems, and automated report generation workflows. It verifies whether AI-generated claims are supported by provided source documents, catching hallucinations before they reach end users.

Is Bespoke-Minicheck a content moderation model?

No. Bespoke-Minicheck is a factual grounding model — it checks whether claims are supported by source documents. For content moderation (detecting harmful, toxic, or policy-violating content), use Llama Guard 3 or ShieldGemma instead.

Can it run on the same server as my primary LLM?

Yes. Bespoke-Minicheck requires approximately 1.5GB of RAM or VRAM, making it lightweight enough to run alongside a primary 7B–8B parameter model on a single GPU instance without meaningful performance impact on either model.
